Let the app start a Garmin sync
  1. On GitHub open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token (or tap here).
  2. Name it, set an expiry (90 days or longer), and under Repository access choose Only select repositories → DailyDisciplines.
  3. Under Permissions → Repository permissions set Actions to Read and write. Leave everything else off.
  4. Generate, copy the token (starts with github_pat_) and paste it below.
The token is kept only on this phone. It can only start the sync, nothing else.
